# 缩略图批量生成工具

## 概述

`generate-thumbnails.js` 是一个批量生成缩略图的Node.js脚本，用于预先生成 `public/media` 目录下所有图片的缩略图，避免用户首次访问时的等待时间。

## 使用方法

### 1. 使用 npm 脚本（推荐）

```bash
npm run generate-thumbnails
```

### 2. 直接运行脚本

```bash
node generate-thumbnails.js
```

## 功能特性

- ✅ **自动扫描**: 递归扫描 `public/media` 目录下的所有子文件夹
- ✅ **格式支持**: 支持 JPG, PNG, GIF, WebP, SVG, BMP 等主流图片格式
- ✅ **EXIF处理**: 自动处理图片的EXIF方向信息，确保缩略图方向正确
- ✅ **缓存复用**: 与API路由使用相同的缓存逻辑，避免重复生成
- ✅ **进度显示**: 实时显示处理进度和统计信息
- ✅ **错误处理**: 单个文件处理失败不影响整体进程
- ✅ **性能统计**: 显示处理时间、文件数量、缓存大小等信息

## 配置说明

脚本使用与API路由相同的配置：

```javascript
const THUMBNAIL_CONFIG = {
    width: 300,        // 缩略图宽度
    height: 300,       // 缩略图高度
    quality: 80,       // JPEG质量 (1-100)
    format: 'jpeg'     // 输出格式
};
```

## 缓存位置

生成的缩略图缓存在：`.next/cache/thumbnails/`

## 何时运行

建议在以下情况运行此脚本：

1. **首次部署**: 在生产环境首次部署时
2. **添加新图片**: 批量添加新图片到media目录后
3. **清理缓存后**: 手动清理缓存目录后
4. **定期维护**: 作为定期维护任务的一部分

## 注意事项

- 脚本会自动创建必要的缓存目录
- 已存在的缓存文件会被跳过，不会重复生成
- 如果修改了THUMBNAIL_CONFIG配置，需要手动清理缓存目录
- 建议在服务器负载较低时运行，避免影响用户体验

## 故障排除

### 权限错误
确保脚本对以下目录有读写权限：
- `public/media/` (读取)
- `.next/cache/thumbnails/` (读写)

### 内存不足
处理大量高分辨率图片时可能遇到内存问题，可以考虑：
- 分批次处理
- 增加Node.js内存限制：`node --max-old-space-size=4096 generate-thumbnails.js`

### Sharp错误
如果遇到Sharp相关错误，尝试重新安装：
```bash
npm uninstall sharp
npm install sharp
```
